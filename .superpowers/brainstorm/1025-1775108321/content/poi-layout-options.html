POI & Itinerary View — Layout Options

How should users visualize their day-by-day plan and distances?

A

List-only with distance indicators

Drag-and-drop ordered list per day. Travel time and distance shown inline between each stop.

Pros

  • Simple, fast to build
  • Clean mobile experience
  • No map API costs

Cons

  • No spatial context
  • Can't see if route backtracks
